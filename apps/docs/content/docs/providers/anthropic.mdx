## Anthropic

Die direkte Anbindung an die [Anthropic-API](https://www.anthropic.com/api) stellt Claude-Modelle für das Standard-Modell bereit.

## Einrichtung

1. API-Key in der [Anthropic Console](https://console.anthropic.com) erstellen.
2. In MDScribe unter `Admin → Einstellungen → Modelle → Verbindungen` einen neuen Provider anlegen:
   - **Protokoll**: `Anthropic`
   - **Base URL**: leer lassen
   - **API-Key**: der erstellte Key
3. Verbindung prüfen und speichern — die verfügbaren Claude-Modelle werden über die Models-API synchronisiert.

## Besonderheiten

- Claude-Modelle verarbeiten Bilder und PDFs nativ: Als Standard-Modell kann die Fähigkeit Dokumente angehakt werden, alternativ eignen sie sich als Dokumenten-Modell.
- Anthropic bietet keine Transkriptions-API; für den Speech-to-Text-Slot wird ein anderer Provider benötigt (z.B. [OpenAI](/providers/openai) oder ein [OpenAI-kompatibler Provider](/providers/openai-compatible)).

## Einordnung für den Datenschutz

Anfragen laufen über die Anthropic-Cloud (US-Anbieter). Prüfen Sie die Data-Processing-Bedingungen Ihres Kontos und die Leitplanken unter [Datenschutz](/privacy), bevor Sie sensible Inhalte verarbeiten.
