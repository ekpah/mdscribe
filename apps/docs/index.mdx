MDScribe erstellt medizinische Dokumente aus **Vorlagen**. Eine Vorlage legt Struktur, Felder und
Formulierungen einmal fest. Für jeden Fall füllen Sie nur noch die Werte aus, von Hand oder per KI
aus Ihren Notizen, Diktaten und Befunden.

## So funktioniert MDScribe

Aus dieser Vorlage …

```markdown
**Gewicht:** {% info "Gewicht" type="number" unit="kg" renderUnit=true /%}
**BMI:** {% calc "BMI" formula="[Gewicht] / ([Groesse] / 100) ^ 2" unit="kg/m²" renderUnit=true %}{% /calc %}
**Raucherstatus:** {% switch "Raucher" type="checkbox" %}{% case "true" %}Raucher{% /case %}{% case "false" %}Nichtraucher{% /case %}{% /switch %}
```

… entsteht mit `Gewicht = 82`, `Groesse = 178` und angehaktem Raucher-Feld:

<Rendered title="Dokument">
  **Gewicht:** <Value>82 kg</Value><br />
  **BMI:** <Value kind="calc">25.88 kg/m²</Value><br />
  **Raucherstatus:** <Value kind="switch">Raucher</Value>
</Rendered>
