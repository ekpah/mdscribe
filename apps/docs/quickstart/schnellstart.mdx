Ziel ist ein Entlassbrief-Textbaustein, den Sie für weitere Fälle wiederverwenden und im Team teilen
können.

## 1. Template

Legen Sie unter **Textbausteine → Neue Vorlage** an:

```markdown
## Aufnahme
{% info "Aufnahmeanlass" description="Kurz und faktenbasiert: Leitsymptom, Beginn, Zuweisung" /%}

## Diagnosen
{% info "Diagnosen" description="Hauptdiagnose zuerst, dann Nebendiagnosen, jeweils mit ICD-10" /%}

## Verlauf
{% info "Verlauf" description="Chronologisch, nur relevante Ereignisse" /%}

## Medikation bei Entlassung
{% info "Entlassmedikation" description="Wirkstoff Dosis Schema, neue Medikamente markieren" /%}

## Procedere
Wiedervorstellung {% switch "Wiedervorstellung" %}{% case "Hausarzt" %}beim Hausarzt in einer Woche{% /case %}{% case "Ambulanz" %}in unserer Ambulanz{% /case %}{% case "bei Bedarf" %}bei Bedarf{% /case %}{% /switch %}.
{% info "Procedere" /%}
```

Die `description` jedes Felds sagt der KI, was hineingehört.

## 2. Informationen

Im Reiter **Informationen**:

```text
- Formeller Stil, Adressat ist der weiterbehandelnde Arzt.
- Diagnosen nach Relevanz sortieren.
- Nur dokumentierte Fakten, keine Vermutungen.
- Fehlt eine Angabe, das Feld leer lassen.
```

## 3. Ein Beispiel

Im Reiter **Beispiele** einen fertigen, erfundenen Entlassbrief hinterlegen. Die KI übernimmt daraus
Stil und Detailgrad, nie Inhalte.

## 4. Ausfüllen

Notizen knapp und gegliedert eingeben, dann **Füllen**:

```text
Aufnahme wegen Dyspnoe und Thoraxschmerz seit 2 Tagen.
Vorgeschichte: arterielle Hypertonie, DM2.
Befunde: Troponin erhöht, ST-Senkungen V4–V6.
Verlauf: Monitoring auf IMC, antithrombotische Therapie, klinische Stabilisierung.
Entlassung in stabilem Zustand, Wiedervorstellung beim Hausarzt.
```

Fehlt etwas, ergänzen Sie die Notizen und füllen erneut, oder Sie korrigieren das Feld direkt im
Text.

## 5. Vor dem Kopieren prüfen

- Diagnosen korrekt und konsistent?
- Daten und Medikation plausibel?
- Nichts erfunden, was nicht in den Notizen stand?
- In der Cloud: keine personenbezogenen Angaben?

<Tip>
  Läuft der Textbaustein gut, legen Sie ihn öffentlich an oder in eine gemeinsame Sammlung, damit
  Kollegen denselben Standard nutzen.
</Tip>
