## Verbundene Zellen

Versehen Sie eine Zelle mit `{% colspan=2 %}` oder `{% rowspan=2 %}`, um sie mit ihren Nachbarn zu
verbinden. Dafür sind weder eigene Tags noch Layout-Metadaten nötig, sodass jeder Markdoc-Renderer
diese Tabellen lesen kann.

## Tabellen ohne Kopfzeile

Beginnen Sie den Tabellenkörper mit `---` direkt nach `{% table %}`:

```markdown
{% table %}
---
* Gewicht
* {% info "gewicht" type="number" unit="kg" renderUnit=true /%}
{% /table %}
```

## Im MDScribe-Editor

Der Editor speichert Tabellen genau in dieser Form, nie als HTML oder als Markdown-Pipe-Tabellen.
Jede Zelle bleibt ein einzelner Absatz mit Inline-Formatierung, Zeilenumbrüchen und Tags. Beim
Verbinden gefüllter Zellen werden deren Inhalte mit Zeilenumbrüchen zusammengefügt. Eigene
Spaltenbreiten oder Kopfspalten bietet der Editor nicht an.

## Rendern

Mit `layout="template"` ergänzt der React-Renderer portable Rahmen, Innenabstände und
Kopfzeilen-Formatierung, die auch beim Kopieren in andere Programme erhalten bleiben.
`serializeMarkdocTable` (aus `markdoc-md/parse`) erzeugt diese Syntax aus Zeilen von Zellen, falls
Sie Tabellen selbst generieren.
