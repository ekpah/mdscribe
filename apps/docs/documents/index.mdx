Unter **Dokumente** verwalten Sie ausfüllbare PDF-Formulare, etwa Anträge, Überweisungen oder
Aufklärungsbögen. Die **Dokumentbibliothek** funktioniert wie die Textbausteine: Suche, Kategorien,
öffentliche und private Einträge.

## Ein Dokument anlegen

1. Unter `/documents/create` ein ausfüllbares PDF hochladen.
2. MDScribe erkennt die Formularfelder. Prüfen Sie Beschriftung (`label`), Beschreibung und
   Optionen. Optional schlägt die KI eine komplette Eingabestruktur vor; der Vorschlag wird gegen
   die tatsächlichen PDF-Felder geprüft, bevor Sie ihn übernehmen.
3. Optional im Reiter **Informationen** allgemeine Ausfüllhinweise hinterlegen. Nutzer sehen sie,
   und die KI berücksichtigt sie beim Ausfüllen.
4. Speichern.

## Ein Dokument ausfüllen

Auf der Seite eines Dokuments stehen links die Eingaben, rechts wahlweise die **PDF-Vorschau** oder
die **Informationen**. Die Vorschau aktualisiert sich bei jeder Eingabe. Wählen Sie eine Eingabe aus,
werden alle zugehörigen PDF-Felder in der Vorschau hervorgehoben.

Mit **Füllen** befüllt die KI die Eingaben aus Text, Audioaufnahmen, Dateien oder einem Foto vom
Handy. Der Textkontext bleibt danach stehen und kann angepasst und erneut verwendet werden.

Ausgefüllte PDFs werden nicht gespeichert: Laden Sie das Ergebnis herunter oder drucken Sie es.

## Wie PDF-Felder zu Eingaben werden

| PDF-Feld | Eingabe in MDScribe |
| --- | --- |
| Textfeld | Texteingabe; alternativ als Auswahl mit eigenen Optionen oder als Checkbox mit eigenem Wert |
| Einzelne Checkbox | Ja/Nein |
| Mehrere Checkboxen mit unterschiedlichen Werten | Eine Auswahl mit diesen Optionen |
| Wiederholte Checkboxen mit demselben Wert | Eine gemeinsame Ja/Nein-Eingabe |
| Auswahlfeld | Auswahl |
| Mehrfachauswahl und nicht unterstützte Felder | Erkannt, aber deaktiviert |

Eine Eingabe kann mehrere PDF-Felder füllen, etwa den Namen auf jeder Seite. Bei
Checkbox-Auswahlen können Sie einzelne Optionen als eigenen Ja/Nein-Schalter abtrennen. Mit
**Checkbox als Option hinzufügen** und einem Klick auf eine andere Checkbox-Karte fügen Sie sie
wieder einer Auswahl hinzu. Deaktivierte Felder bleiben gespeichert, erscheinen aber nicht als
Eingabe.

## Grenzen

| | Höchstens |
| --- | --- |
| Dateigröße | 10 MB |
| Seiten | 500 |
| Formularfelder | 2.000 |
| Formular-Widgets | 5.000 |

Unterstützt werden PDFs mit AcroForm-Formularfeldern. PDFs ohne Formularfelder (etwa
eingescannte Bögen) lassen sich nicht ausfüllen.

## Sichtbarkeit und Bearbeiten

- **Öffentliche** Dokumente sind für alle sichtbar und nutzbar. Angemeldete Nutzer können sie als
  Kopie übernehmen (forken) und anpassen.
- **Private** Dokumente sieht nur der Autor; sie erfordern ein Plus-Abonnement.
- Bearbeiten kann nur der Autor.

<Accordion title="Technische Details: was gespeichert wird">
  Pro Dokument werden gespeichert: das Original-PDF, die Felddefinitionen und die
  Ausfüllhinweise. Die Felddefinitionen bestehen aus `inputs` (die Eingaben; `attributes.primary`
  ist zugleich der Schlüssel der Werte) und `bindings` (Zuordnung von PDF-`fieldName` zu
  `inputId`, Aktivierung, optionale `valueMap`). Mehrere Bindings dürfen dieselbe Eingabe
  verwenden. Feldtyp und Widget-Daten werden beim Bearbeiten aus dem PDF gelesen und nicht doppelt
  gespeichert. Es wird kein Markdoc-Text gespeichert.
</Accordion>
